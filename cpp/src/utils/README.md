# Subdirectory for MOLE 2.0 C++ Utilities and Wrappers

Subdirectory and Pathname: **mole/cpp/src/utils**

## Purpose

This subdirectory contains functionality that either extends the MOLE
library's functionality through a third-party software library or
extends existing functionality from other software libraries and
customizes it to the MOLE library.  

## List of files in this subdirectory (alphabetical order)

+ **utils.cpp**: a class implementation with MOLE basic utilities for
sparse matrices and meshes.
