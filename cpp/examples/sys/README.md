# Subdirectory for MOLE 2.0 C++ grid examples

Subdirectory and Pathname: **mole/cpp/examples/sys/**

## Purpose

Subdirectory containing examples of MOLE's system functionality like
the error handling.

## List of Files in This Subdirectory

+ **CMakeLists.txt**: support the building of MOLE 2.0 C++ examples of
MOLE system functionality
+ **err_stack_ops.cpp**: a simple C++ example of how the error log
+ **err_write_file.cpp**: an example on how to use output MOLE errors
to a file. It catches C++ exceptions.
+ **err_write_stdout.cpp**: an example on how to use output MOLE
errors to a standard output (default screen). It catches C++ exceptions.
+ **README.md**: (this file)
